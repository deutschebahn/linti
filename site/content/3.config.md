title: Configurator
description: Build a linti.yaml for your project from a use case, then fine-tune every rule.
---

::config-configurator
::

Use the add button to create and name a configuration from a template; Recommended uses LinTi's standard settings. Adjust the rules or edit the YAML directly; the form follows along. **Save configuration** stores it in this browser, the switcher moves between configurations, and **Manage configurations** offers duplicate, rename, export, and import.

Download the YAML for your project or try the draft in the playground. A share link opens a configuration as a draft that you can save if you like.
