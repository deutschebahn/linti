---
title: Playground
description: Paste a whole TI process, lint it, and apply auto-fixes in your browser.
---

::process-playground
::

The editor accepts .ti files (plain or with #region sections), PA code format and YAML format; the format is detected automatically. Everything runs locally in your browser via Pyodide, so your code is never sent to a server.

The active configuration from the [configurator](/config) is used automatically.
